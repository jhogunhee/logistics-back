# WMS 전략 공통코드 정리 — 덤프 데이터 추출

> 출처: `Company/dbData/TCO_CC_COMNCD_GRP.sql` · `Company/dbData/TCO_CC_COMNCD.sql` (운영 덤프, 2026-08-02 추출)
> 자매 문서: `docs/입고검수적치전략.html` · `docs/출고웨이브전략.html` · `docs/출고할당분배전략.html`
>
> 위 전략 분석 3부작에서 참조된 공통코드 그룹 **27개**를 덤프에서 전수 추출해 계층 관계대로 정리한 문서다.
> 코드명·정렬순서·사용자정의필드(FLD)·상태는 모두 덤프 원본 값 그대로이며, 해석이 필요한 부분은 "추정"으로 표시했다.

---

## 1. 읽는 법 — 사용자정의필드(USR_DEF_FLD)와 상태코드

공통코드 한 행은 `USR_DEF_FLD_1~10`으로 다른 그룹·컬럼과 연결된다. 전략 코드에서 각 필드는 다음 용도로 쓰인다.

| 필드 | 용도 (덤프 관찰 기반) |
|---|---|
| `FLD_1` | **하위 코드그룹** — 이 코드를 선택하면 다음 단계에서 보여줄 그룹 (예: 전략유형 `22` → 적용구분 그룹 `C00004`) |
| `FLD_2` | **입력유형** (추정): `10` 직접입력 · `20` 코드선택 · `99` 값 입력 없음 |
| `FLD_3` | **값 코드그룹** — 입력유형이 코드선택일 때 값을 고를 그룹 (예: 로케이션유형 → `C00275`) |
| `FLD_4` | **매핑 컬럼 또는 동작 식별자** — 조건 비교에 쓸 데이터 컬럼명(`OUTB_TYP_CD`, `FLTNO`), 또는 실행 로직 분기 키(`FXNG_LOC`, `ALOC_DIV`) |
| `FLD_5` | **용도 태그** — 할당 출고수량(C00015)에서만 사용: `QTY` / `STATUS` |

상태(`DAT_ST_CD`): `01` 사용 · `02`/`03` 비활성(미사용/삭제 추정). 본 문서에서는 `01`이 아닌 코드에 ⚠ 표시.

## 2. 루트 — C00002 전략 유형

모든 전략 계층의 출발점. `FLD_1`이 적용구분 그룹, `FLD_3`이 적용대상 그룹을 가리킨다.

| 코드 | 이름 | FLD_1 (적용구분 그룹) | FLD_3 (적용대상 그룹) | 비고 |
|---|---|---|---|---|
| `11` | 입고제약 | `C00024` | — | 검수 전략. 적용대상 계층 없음 (등록 시 전부 실행) |
| `12` | 입고적치 | `C00003` | `C00030` | 적용대상 = 입고유형 |
| `21` | 출고웨이브 | `C00006` | — | 적용대상 계층 없음 |
| `22` | 재고할당 | `C00004` | `C00031` | 적용대상 = 거래처유형·출고유형 |
| `31` | 보충 | `C00005` | — | **분석 3부작 범위 밖** — 덤프에 정의만 존재. C00005는 C00008·C00009·C00010을 재사용 |

## 9. 덤프에서 확인된 특이사항

1. **그룹명 중복·오칭**: `C00023`과 `C01524`의 그룹명이 둘 다 "분배단위"다. 실제 역할은 C00023 = 우선분배 **대상 선별 조건**, C01524 = **분배량 단위**로 전혀 다르다. 분석 문서의 "화면 라벨만 보고 오해" 특이점의 데이터 차원 원인.
2. **비활성(02/03) 코드가 체인 곳곳에 남아 있다**: 할당 구분 `80 재고상태`(03), 로케이션 기준 `30 재고상태`(03), 적치 조건 `D02 제조일자`(02). 특히 적치 D02는 **코드 데이터도 비활성, 구현도 빈 껍데기**로 이중으로 죽어 있다.
3. **매핑 컬럼(FLD_4)이 비어 있는 조건기준**: 웨이브 조건 `31 납품처그룹`·`32 납품처유형`은 값 그룹은 있어도 매핑 컬럼이 없어 실행 시 비교 대상이 없다 — 화면 등록은 가능하나 동작하지 않는 옵션.
4. **C00014(제약)는 검수와 할당이 공유하지만 구현 상태가 다르다**: 검수는 3종 모두 구현, 할당은 D02만 구현(C10·D03은 E099 예외). 같은 코드가 문맥에 따라 동작/장애로 갈린다.
5. **전략유형 `31 보충`이 덤프에 존재**한다 (C00005: 재고위치 From `C00008` · 보충위치 To `C00009` · 보충 순서 `C00010` 재사용). 분석 3부작에는 다루지 않은 다섯 번째 전략 계층.
6. **입력유형(FLD_2) 데이터 불일치**: 웨이브 조건 `21 차량편수`는 입력유형 10(직접입력)이면서 값 그룹 C01351을 함께 갖는다. 화면 동작은 구현에 따라 달라졌을 것.
7. 이 코드 체계 전체가 신규 설계(`docs/전략시스템_재설계안.md`)에서 **코드 레지스트리(Descriptor)와 필드 레지스트리로 대체되는 대상**이다. 본 문서는 그 마이그레이션 시 "기존에 실제 존재하던 선택지 전수 목록"의 기준 자료로 쓸 수 있다.
